# DeskTick

デスクトップの隅に日付と時刻を常に表示する、Windows用の時計アプリです。  
通知領域に常駐し、定時・起立・水分補給・食事などのお知らせも出します。

- 最前面に表示する時計（フォント・色・表示形式・位置を変更可能）
- NTPサーバの時刻に合わせた表示
- 定時・起立・水分補給・食事・カスタムの通知（一定間隔/指定時刻/併用）
- 設定はexeと同じディレクトリのconfig.jsonで管理

## 使い方

### インストール

DeskTick.exeとconfig.jsonを同じディレクトリに置いて、DeskTick.exeを起動します。  
インストーラーはありません。

- config.jsonがない場合は、初回起動時に初期値で作成されます。
- 単体exe（portable形式）のため、起動のたびに一時ディレクトリへ展開します。  
  時計が表示されるまで10秒ほどかかります。
- Program Filesなど書き込み権限のない場所に置くと、設定を保存できません。

### 操作

| 操作        | 方法                                            |
| ----------- | ----------------------------------------------- |
| 移動        | 時計をドラッグ                                  |
| メニュー    | 時計を右クリック/通知領域のアイコンを右クリック |
| 表示/非表示 | 通知領域のアイコンをクリック                    |
| 設定画面    | メニューの「設定...」                           |
| 終了        | メニューの「終了」、または時計をクリックしてEsc |

ドラッグで動かした位置は保存されません。  
次回起動時と「デフォルト位置に戻す」では、設定した位置に戻ります。

### 設定画面

| タブ        | 内容                                                                   |
| ----------- | ---------------------------------------------------------------------- |
| 表示        | フォント、文字サイズ、文字色、背景色、影、余白、角丸（プレビュー付き） |
| 表示形式    | 1行目・2行目の書式、ロケール、タイムゾーン                             |
| 位置        | ディスプレイ、基準の角、端からの余白、最前面に固定                     |
| 時刻同期    | NTPのオン/オフ、サーバ、同期間隔、同期状態                             |
| 通知        | 各アラートのオン/オフ、スケジュール、文言、テスト通知                  |
| 起動        | Windows起動時に自動で開始                                              |
| 情報/ヘルプ | バージョン、設定ファイルの場所、使い方                                 |

設定は変更するとすぐ反映され、config.jsonに保存されます。
config.jsonを直接編集した場合も、保存すると自動で読み込み直します（JSONが不正な間は無視します）。

### 表示形式の書式

| トークン   | 内容                | 例              |
| ---------- | ------------------- | --------------- |
| YYYY / YY  | 年/年の下2桁        | 2026 / 26       |
| M / MM     | 月                  | 1 / 01          |
| MMM / MMMM | 月名                | Oct / October   |
| D / DD     | 日                  | 5 / 05          |
| week / ddd | 曜日（短縮）        | Sat/土          |
| dddd       | 曜日                | Saturday/土曜日 |
| H / HH     | 時（24時間制）      | 9 / 09          |
| h / hh     | 時（12時間制）      | 9 / 09          |
| A          | 午前/午後           | AM/午前         |
| m / mm     | 分                  | 5 / 05          |
| s / ss     | 秒                  | 5 / 05          |
| [文字]     | [ ]内はそのまま表示 | [Today] → Today |

曜日・月名・午前/午後の言語はロケール（例：en-US, ja-JP）で決まります。  
書式の中の`M`・`D`・`h`・`s`・`A`などはトークンとして置き換わるため、文字として表示したい場合は`[ ]`で囲んでください。

### 通知

| アラート       | 初期値                     | 補足                                                                                                                           |
| -------------- | -------------------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| 定時           | 平日18:00                  | 時刻1つ+曜日                                                                                                                   |
| 起立           | 平日9:00〜18:00、30分ごと  | 座っている時間を30分未満で区切る人ほど死亡リスクが低かったという研究（Diaz et al., Annals of Internal Medicine, 2017）に基づく |
| 水分補給       | 平日9:00〜18:00、60分ごと  | 飲み物からの1日の摂取目安（EFSA:約1.6〜2.0L）を、活動時間中にコップ1杯ずつ摂るための目安                                       |
| 朝食/昼食/夕食 | 7:30 / 12:00 / 19:00、毎日 | 初期状態で有効なのは昼食のみ                                                                                                   |
| カスタム       | なし                       | 設定画面から追加                                                                                                               |

定時以外のアラートは、次のスケジュールを組み合わせられます。

- **一定間隔**：○時間○分ごと。時間帯の開始時刻から数えます（例：9:00開始・30分 → 9:30, 10:00, …, 18:00）。
- **指定時刻**：時刻を複数登録できます。
- **併用**：両方をオンにできます。同じ分に重なった場合は1回だけ通知します。
- **曜日**：通知する曜日を指定します。カスタムアラートは「繰り返しなし（日付を指定）」も選べます。

タイトルとメッセージの{emoji}は、絵文字リストからランダムに選んだ1つに置き換わります。  
メッセージは複数登録でき、通知のたびにランダムで1つ選ばれます。

アプリが起動している間だけ通知します。  
起動していなかった時間やスリープ中に過ぎた時刻は、あとから通知しません。

### 時刻同期（NTP）

PCの時計は変更せず、時計の表示と通知の判定だけをNTPサーバの時刻に合わせます（初期値：ntp.nict.jp、60分ごと）。  
UDP 123番ポートを使用します。  
同期できない場合は前回のずれ（初回はPCの時刻）を使います。

### PCに作成されるもの

exeとconfig.json以外に、次のものが作られます。

| 場所                                                      | 用途                                                        |
| --------------------------------------------------------- | ----------------------------------------------------------- |
| %APPDATA%\DeskTick\                                       | Electronのキャッシュ、通知用アイコン                        |
| スタートメニューのDeskTick.lnk                            | Windowsでトースト通知を出すために必要（最初の通知時に作成） |
| HKCU\Software\Classes\AppUserModelId\jp.melpwill.desktick | 通知に表示するアプリ名とアイコン                            |
| HKCU\...\CurrentVersion\Run                               | 「Windows起動時に開始」をオンにした場合のみ                 |

自動スタートアップには、その時点のexeの場所が登録されます。  
exeを移動した場合は、一度オフにしてからオンにし直してください。

## 開発

### 必要なもの

- Windows（exeのビルドと動作確認）
- Node.js 22.13以上（24推奨）
- pnpm 11（package.jsonのpackageManagerで固定。corepackで自動的に使われます）

### セットアップ

```sh
corepack enable   # 初回のみ
pnpm install
```

### コマンド

| コマンド                        | 内容                                                              |
| ------------------------------- | ----------------------------------------------------------------- |
| pnpm start                      | ビルドして開発起動（プロジェクト直下のconfig.jsonを使用）         |
| pnpm dist                       | exeをビルドし、release/DeskTick/にDeskTick.exeとconfig.jsonを出力 |
| pnpm check                      | 下の4つをまとめて実行                                             |
| pnpm lint                       | ESLint                                                            |
| pnpm format / pnpm format:check | Prettierで整形/整形済みか確認                                     |
| pnpm typecheck                  | TypeScriptの型チェック                                            |
| pnpm test / pnpm test:coverage  | Vitest/カバレッジ付き（100%未満で失敗）                           |

pnpm startに`-- --settings`を付けると、起動時に設定画面が開きます。  
`--settings=alerts`のようにタブも指定できます。

VS Codeの統合ターミナルでは環境変数ELECTRON_RUN_AS_NODE=1が設定されているため、Electronが起動しません。  
外部のターミナルを使うか、この変数を外して実行してください。

### CI/リリース（GitHub Actions）

.github/workflows/ci.ymlで次のジョブを実行します。

| タイミング           | ジョブ                                                                  |
| -------------------- | ----------------------------------------------------------------------- |
| PR、ブランチへのpush | lint・format・typecheck → test（カバレッジとJUnitをArtifactとして保存） |
| タグvX.Y.Zのpush     | 上記に加えて、Windowsランナーでのexeのビルド → GitHub Releaseの作成     |

リリースの手順：

1. package.jsonのversionを上げる（例：1.1.0）
2. 同じバージョンのタグ（例：v1.1.0）を作成してpushする

タグとversionが一致しない場合、ビルドジョブは失敗します。  
ReleaseにはDeskTick.exeとconfig.jsonが添付されます。
