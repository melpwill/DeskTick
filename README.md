# DeskTick

デスクトップの隅に日付と時刻を常に表示する、Windows用の時計アプリです。  
通知領域に常駐し、定時・起立・水分補給・食事などのお知らせも出します。

- 最前面に表示する時計（フォント・色・表示形式・位置を変更可能）
- NTPサーバの時刻に合わせた表示
- 定時・起立・水分補給・食事・カスタムの通知（一定間隔/指定時刻/併用）
- 設定はexeと同じディレクトリのconfig.jsonで管理
- GitHubのリリースからの更新（署名を確かめてからexeを差し替え）

## 使い方

### インストール

DeskTick.exeとconfig.jsonを同じディレクトリに置いて、DeskTick.exeを起動します。  
インストーラーはありません。

- config.jsonがない場合は、初回起動時に初期値で作成されます。
- 単体exe（portable形式）のため、起動のたびに一時ディレクトリへ展開します。  
  時計が表示されるまで10秒ほどかかります。
- Program Filesなど書き込み権限のない場所に置くと、設定を保存できません。

### 操作

| 操作        | 方法                                            |
| ----------- | ----------------------------------------------- |
| 移動        | 時計をドラッグ                                  |
| メニュー    | 時計を右クリック/通知領域のアイコンを右クリック |
| 表示/非表示 | 通知領域のアイコンをクリック                    |
| 設定画面    | メニューの「設定...」                           |
| 終了        | メニューの「終了」、または時計をクリックしてEsc |

ドラッグで動かした位置は保存されません。  
次回起動時と「デフォルト位置に戻す」では、設定した位置に戻ります。

### メニュー

| 項目                    | 内容                                                                 |
| ----------------------- | -------------------------------------------------------------------- |
| 設定...                 | 設定画面を開く                                                       |
| 時計を隠す / 時計を表示 | 時計の表示・非表示を切り替える（通知領域のアイコンのクリックと同じ） |
| デフォルト位置に戻す    | ドラッグで動かした時計を、「位置」タブで設定した位置に戻す           |
| 最前面に固定            | ほかのウィンドウより常に手前に表示する（「位置」タブの設定と同じ）   |
| 通知を一時停止          | トーストとダイアログを一定時間止める（詳しくは[通知](#通知)）        |
| 更新を確認...           | 新しいバージョンを確認する（詳しくは[更新](#更新)）                  |
| バージョン情報 / ヘルプ | 設定画面の「情報/ヘルプ」タブを開く                                  |
| 終了                    | DeskTickを終了する                                                   |

### 設定画面

| タブ        | 内容                                                                   |
| ----------- | ---------------------------------------------------------------------- |
| 表示        | フォント、文字サイズ、文字色、背景色、影、余白、角丸（プレビュー付き） |
| 表示形式    | 1行目・2行目の書式、ロケール、タイムゾーン                             |
| 位置        | ディスプレイ、基準の角、端からの余白、最前面に固定                     |
| 時刻同期    | NTPのオン/オフ、サーバ、同期間隔、同期状態                             |
| 通知        | 各アラートのオン/オフ、スケジュール、文言、通知方法、テスト通知        |
| 起動        | Windows起動時に自動で開始                                              |
| 更新        | 更新の方法、トーストで知らせるか、今すぐ確認・更新、変更内容           |
| 情報/ヘルプ | バージョン、設定ファイルの場所、リリースノート、使い方、ライセンス     |

設定は変更するとすぐ反映され、config.jsonに保存されます。
config.jsonを直接編集した場合も、保存すると自動で読み込み直します（JSONが不正な間は無視します）。

### 表示形式の書式

| トークン   | 内容                | 例              |
| ---------- | ------------------- | --------------- |
| YYYY / YY  | 年/年の下2桁        | 2026 / 26       |
| M / MM     | 月                  | 1 / 01          |
| MMM / MMMM | 月名                | Oct / October   |
| D / DD     | 日                  | 5 / 05          |
| week / ddd | 曜日（短縮）        | Sat/土          |
| dddd       | 曜日                | Saturday/土曜日 |
| H / HH     | 時（24時間制）      | 9 / 09          |
| h / hh     | 時（12時間制）      | 9 / 09          |
| A          | 午前/午後           | AM/午前         |
| m / mm     | 分                  | 5 / 05          |
| s / ss     | 秒                  | 5 / 05          |
| [文字]     | [ ]内はそのまま表示 | [Today] → Today |

曜日・月名・午前/午後の言語はロケール（例：en-US, ja-JP）で決まります。  
書式の中の`M`・`D`・`h`・`s`・`A`などはトークンとして置き換わるため、文字として表示したい場合は`[ ]`で囲んでください。

### 通知

| アラート       | 初期値                     | 補足                                                                                                                           |
| -------------- | -------------------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| 定時           | 平日18:00                  | 時刻1つ+曜日                                                                                                                   |
| 起立           | 平日10:15〜16:45、30分ごと | 座っている時間を30分未満で区切る人ほど死亡リスクが低かったという研究（Diaz et al., Annals of Internal Medicine, 2017）に基づく |
| 水分補給       | 平日10:30〜17:30、60分ごと | 飲み物からの1日の摂取目安（EFSA:約1.6〜2.0L）を、活動時間中にコップ1杯ずつ摂るための目安                                       |
| 朝食/昼食/夕食 | 7:30 / 12:00 / 19:00、毎日 | 初期状態で有効なのは昼食のみ                                                                                                   |
| カスタム       | なし                       | 設定画面から追加                                                                                                               |

定時以外のアラートは、次のスケジュールを組み合わせられます。

- **一定間隔**：○時間○分ごと。時間帯の開始時刻から数えます（例：9:00開始・30分 → 9:30, 10:00, …, 18:00）。
- **指定時刻**：時刻を複数登録できます。
- **併用**：両方をオンにできます。同じ分に重なった場合は1回だけ通知します。
- **曜日**：通知する曜日を指定します。カスタムアラートは「繰り返しなし（日付を指定）」も選べます。

タイトルとメッセージの{emoji}は、絵文字リストからランダムに選んだ1つに置き換わります。  
メッセージは複数登録でき、通知のたびにランダムで1つ選ばれます。

通知方法は、アラートごとに「トースト」（Windowsの通知）と「ダイアログ」から選べます。  
ダイアログは画面の右下に、OKを押すまで表示されます。枠とボタンの色はアラートごとに指定できます。  
ダイアログはWindowsの集中モード（応答不可）の対象外です。

プレゼンやゲームの間は、メニューの「通知を一時停止」で、トーストとダイアログの両方を止められます。  
止める時間は30分・1時間・2時間・再開するまで、から選べます。  
停止中はメニューに「通知を再開」が表示され、通知領域のアイコンにマウスを重ねると停止の終了時刻がわかります。

- 停止中に過ぎた時刻は、再開後に通知しません。
- 設定画面のテスト通知は、停止中でも表示します。
- 停止状態は保存しません。アプリを起動し直すと、通知が再開します。

アプリが起動している間だけ通知します。  
起動していなかった時間やスリープ中に過ぎた時刻は、あとから通知しません。

### 時刻同期（NTP）

PCの時計は変更せず、時計の表示と通知の判定だけをNTPサーバの時刻に合わせます（初期値：ntp.nict.jp、60分ごと）。  
UDP 123番ポートを使用します。  
同期できない場合は前回のずれ（初回はPCの時刻）を使います。

### 更新

GitHubのリリースを確認して、新しいバージョンに更新できます。  
「更新」タブの「更新の方法」で、次の3つから選べます（初期値：確認して知らせる）。

| 更新の方法         | 動作                                                                                    |
| ------------------ | --------------------------------------------------------------------------------------- |
| 自動で更新する     | 新しいバージョンをダウンロードしてexeを差し替える。次に起動したときから新しいバージョン |
| 確認して知らせる   | 新しいバージョンがあれば知らせる。メニューか「更新」タブのボタンで更新する              |
| 自動では確認しない | 自分で「今すぐ確認」/メニューの「更新を確認...」を押したときだけ確認する                |

- 起動して1分後に1回目、その後は1日1回確認します（失敗したときは1時間後にもう一度）。
- 「トーストで知らせる」をオフにすると、新しいバージョンや更新の完了をトーストで知らせません。
- 知らせたくないバージョンは「このバージョンを通知しない」で止められます。
- 更新しても、config.jsonはそのまま引き継ぎます。
- ダウンロードしたあとは、メニューの「再起動してvX.Y.Zに更新」で、すぐに新しいバージョンにできます。そのまま使い続けても、DeskTickを終了したときに差し替えます。

ダウンロードしたファイルは、次の順に確かめてから使います。1つでも合わなければ更新しません。

1. 接続先がGitHub（api.github.com、github.com、配布用のgithubusercontent.com）のHTTPSであること（転送先も1つずつ確認）
2. リリースに付いたDeskTick-update.jsonの署名（Ed25519）が、アプリに埋め込んだ開発者の公開鍵で検証できること
3. DeskTick-update.jsonに書かれたバージョンがリリースのタグと一致し、今より新しいこと
4. ダウンロードしたexeの大きさとSHA-256が、DeskTick-update.jsonの内容と一致すること

exeの差し替えは次のように行います。

1. 新しいexeをDeskTick.exe.newとして書き込む
2. DeskTickを終了するときに、差し替え用のPowerShellをWMIで起動する（実行中のDeskTick.exeは名前を変えられないため。DeskTickと一緒に終了させられないよう、DeskTickとは別に起動する）
3. PowerShellは、DeskTickが終わるのを待ってから（最大2分）、DeskTick.exeをDeskTick.exe.oldに名前を変え、DeskTick.exe.newをDeskTick.exeにする（失敗したら元に戻す）。「再起動して更新」のときは、続けて新しいバージョンを起動する
4. 新しいバージョンが起動して1分たったら、DeskTick.exe.oldを削除する

新しいバージョンが起動しない場合は、DeskTickを終了してからDeskTick.exe.oldをDeskTick.exeに戻してください。  
PowerShellを起動できない環境では、終了しても差し替わりません。リリースページから手動で更新してください。

exeのあるフォルダーに書き込めない場合（Program Filesなど）は、差し替えずに知らせるだけにします。  
「リリースページを開く」から手動でダウンロードしてください。  
社内のプロキシなど、OSのプロキシ設定にしたがって接続します。

新しいバージョンでconfig.jsonの形が変わった場合は、起動時に自動で変換し、変換前の内容をconfig.json.bakに残します。  
古いバージョンに戻した場合など、config.jsonがアプリより新しいバージョンで作られているときは、config.jsonを上書きしません（変更はその間だけ有効）。

### PCに作成されるもの

exeとconfig.json以外に、次のものが作られます。

| 場所                                                      | 用途                                                        |
| --------------------------------------------------------- | ----------------------------------------------------------- |
| %APPDATA%\DeskTick\                                       | Electronのキャッシュ、通知用アイコン                        |
| スタートメニューのDeskTick.lnk                            | Windowsでトースト通知を出すために必要（最初の通知時に作成） |
| HKCU\Software\Classes\AppUserModelId\jp.melpwill.desktick | 通知に表示するアプリ名とアイコン                            |
| HKCU\...\CurrentVersion\Run                               | 「Windows起動時に開始」をオンにした場合のみ                 |
| exeと同じディレクトリのDeskTick.exe.new / .old            | 更新中の一時ファイル（更新が終わると削除）                  |
| exeと同じディレクトリのconfig.json.bak                    | config.jsonの形を変換したときの、変換前の内容               |

自動スタートアップには、その時点のexeの場所が登録されます。  
exeを移動した場合は、一度オフにしてからオンにし直してください。
