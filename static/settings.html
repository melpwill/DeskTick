時刻同期 (NTP)

-

PCの時計は変更せず、時計の表示だけをNTPサーバの時刻に合わせます。
同期できない場合は前回のずれ（初回はPCの時刻）を使います。
UDP 123番ポートを使用します。

通知

アプリが起動している間だけ通知します。
起動していなかった時間やスリープ中の時刻は、あとから通知しません。
プレゼンやゲームの間は、メニューの「通知を一時停止」で止められます（停止中の時刻もあとから通知しません）。

起動

DeskTick
バージョン

デスクトップの隅に日付と時刻を常に表示する時計アプリです。
通知領域に常駐し、次の機能があります。

  • 最前面に表示する時計 (フォント・色・表示形式・位置を変更可能)
  • NTPサーバの時刻に合わせた表示
  • 定時・起立・水分補給・食事・カスタムの通知 (一定間隔 / 指定時刻)

使い方

移動 時計をドラッグ
メニュー 時計を右クリック / 通知領域のアイコンを右クリック
表示 / 非表示 通知領域のアイコンをクリック
終了 メニューの「終了」、または時計をクリックして Esc

設定はexeと同じディレクトリのconfig.jsonに保存され、変更するとすぐ反映されます。
config.jsonを直接編集した場合も、保存すると自動で読み込み直します（JSONが不正な間は無視）。
config.jsonがない場合は初期値で作成されます。
配布はexeとconfig.jsonの2ファイルだけで動作します。

メニュー

設定... この設定画面を開く
時計を隠す / 時計を表示 時計の表示・非表示を切り替える（通知領域のアイコンのクリックと同じ）
デフォルト位置に戻す ドラッグで動かした時計を、「位置」タブで設定した位置に戻す
最前面に固定 ほかのウィンドウより常に手前に表示する（「位置」タブの設定と同じ）
通知を一時停止 30分 / 1時間 / 2時間 / 再開するまで、トーストとダイアログを止める。
停止中は「通知を再開」に変わる。アプリを起動し直すと再開する
バージョン情報 / ヘルプ このタブを開く
終了 DeskTickを終了する
